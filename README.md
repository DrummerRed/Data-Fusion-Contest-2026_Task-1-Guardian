# Data Fusion Contest 2026 — Задача «Страж»

Моё первое участие в соревновании по машинному обучению.

Подробное описание задачи:  
https://ods.ai/tracks/data-fusion-2026-competitions/competitions/data-fusion2026-guardian  

**Задача:** Построение модели антифрода для предсказания неподтверждённых (мошеннических) банковских операций.  
**Место:** 287 из 574 участников    

## Описание задачи

В рамках трека "Data Fusion 2026" решалась задача бинарной классификации банковских транзакций.  
Цель — предсказать, подтвердит ли клиент операцию или она окажется неподтверждённой (target = 1, "красный" класс).

- **Метрика:** PR-AUC  
- **Данные:** около 200 миллионов операций клиентов, целевой класс содержит всего 51000 записей  

## Что я использовал

- Основная модель: **CatBoost**
- Feature Engineering
- Эксперименты с разными весами классов, гиперпараметрами и признаками

## Структура репозитория

- `notebooks/` — содержит ноутбуки с итоговым решением
- `experiments/` — как и вся ветка "develop" содержит основную проделанную работу над данными и моделью (старые попытки и промежуточные эксперименты)
- `models/` — сохранённые модели
